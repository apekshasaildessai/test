## How to Use

### Viewing the Presentation
1. Open `index.html` in a web browser
2. Click "View Presentation" to start
3. Use navigation buttons or keyboard controls

### Navigation Controls
- **Next Slide**: Right arrow, spacebar, or "Next" button
- **Previous Slide**: Left arrow or "Previous" button
- **First Slide**: Home key
- **Last Slide**: End key
- **Fullscreen**: F11 key
- **Touch/Swipe**: Supported on mobile devices

### Features
- **Professional Design**: Credora Capital branding with gold accents
- **Interactive Navigation**: Multiple control methods
- **Responsive Layout**: Works on all screen sizes
- **Print Ready**: Can be printed or exported to PDF
- **Auto-save Progress**: Remembers last viewed slide
- **Smooth Animations**: Professional slide transitions

### Converting to PowerPoint
To convert to actual PowerPoint format:
1. Open the presentation in a web browser
2. Use browser print function → "Save as PDF"
3. Import PDF into PowerPoint for editing
4. Or use online HTML-to-PowerPoint conversion tools

### Customization
- Edit `presentation_styles.css` for design changes
- Modify `credora_presentation.html` for content updates
- Update `presentation_script.js` for functionality changes
